# imtdeskgui Module

## Overview

The **imtdeskgui** module provides QML user interface components for the
Service Desk ticketing system.

## QML Components

| Component              | Purpose                                     |
|------------------------|---------------------------------------------|
| `TicketBadge.qml`     | Status/priority badge pill                  |
| `TicketCreateDialog.qml` | Modal dialog for creating new tickets    |
| `TicketListPanel.qml`  | Filterable list of tickets                 |
| `TicketView.qml`       | Detail view for a single ticket            |

## Related Modules

- **imtdesk** — Service Desk domain model
- **imtdeskdb** — Database persistence layer
- **imtdeskgql** — GraphQL API binding
