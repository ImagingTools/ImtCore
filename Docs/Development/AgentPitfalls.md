# Ловушки проекта для агентов (architect / coder / tester)

Список накопленных граблей ImtCore и смежных репозиториев. Агенты читают его перед работой. Если пункт устарел, исправьте его здесь, а не в промптах агентов.

## QML и веб-клиент
- QML грузится из ресурса `qrc:/qml`: после правок нужна пересборка ресурсов (`imtcontrolsqml` / `imtguiqml`), иначе работает старый интерфейс.
- Веб-клиент Lisa получает правки QML только через пересборку `WebCompilerlisa`. В ProLife для пересборки web-бандла удалите `AuxInclude/Web/Resources/index.js`.
- Не используйте `Qt.binding` и `Qt.callLater`. Вместо них - Timer с ненулевым interval (repeat-Timer с interval 0 не срабатывает).
- `item.children` - не JS-массив: `.slice()` бросает исключение и молча убивает обработчик.
- Значения из моделей - не JS-строки: перед поиском по карте приводите через `String()`.
- Параметры диалога приходят после `onCompleted` (openDialog выставляет их после создания).
- Кэшированные модели коллекций заполняются на месте: `ComboBox.onModelChanged` срабатывает один раз.
- `ViewBase` и `ApplicationMain` общесистемные (десятки потребителей): не реструктурируйте.
- Граф QML-модулей циклический (в `qmldir` нет `depends`); Style приходит из Acf.
- Исключения обработчиков в JQML скрыты, пока в финальном URL нет `#jqdebug`.
- `import imtcontrols` в делегатах ячеек стоит дорого на каждый экземпляр.

## C++ / ACF / SDL
- `.acc`-реестры компилируются в exe: новый компонент требует записи в `ExportedComponents`.
- Атрибут компонента ACF передаётся через `.acc` вручную, шаг за шагом; необязательный атрибут без значения невалиден (разыменование падает по assert).
- `QString::arg(int, int)` попадает в перегрузку fieldWidth и оставляет `%2` буквально.
- Имена полей SDL могут конфликтовать с `CItemModelBase` (`finished` и т.п.): ошибка C2385 в сгенерированной обёртке.
- SDL namespace определяет каталог генерации и должен совпадать с CMake-целью SDL.
- После смены SDL-типа ninja может не пересобрать зависимые файлы: проверяйте, что пересобрались все пользователи.
- Undo-архивы не содержат `IVersionInfo`: поля, зависящие от версии, пропадают.
- Метаданные БД приходят как `QJsonValue`: `toByteArray()` возвращает пустое значение.
- Асинхронный `SendRequest` на worker-потоке приводит к зависанию: GQL-вызовы должны идти на потоке приложения.

## Сборка и окружение
- Правя файлы, сохраняйте CRLF. `sed -i` по всему файлу даёт diff на весь файл.
- LNK1168: остановите процесс, держащий exe, не переименовывайте файл.
- Для Puma нужен `vcvars64`; ImtCore собирается отдельно.

## Тесты
- Перед baseline-прогонами GUI-наборов восстанавливайте тестовые БД: иначе дрейф данных даёт детерминированные расхождения скриншотов.
- Tab не коммитит поле ввода: для коммита снимайте фокус (blur).
- Раскладка колонок хранится на сервере для каждого пользователя: разделяемое состояние даёт флаки в скриншотах.
- Скриншоты не переносятся между машинами (шрифты, автообновление Chrome, spellchecker).
- Тесты должны уметь упасть: проверки, которые всегда истинны, скрывали сломанные функции.
