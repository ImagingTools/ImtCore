## 🏗️ Обзор архитектуры

QML-мир ImtCore организован в несколько уровней:

```
┌─────────────────────────────────────────────────────────────┐
│                    Доменно-специфичные модули                │
│  imtauthgui · imtchatgui · imtdeskgui · imtlicgui · ...    │
├─────────────────────────────────────────────────────────────┤
│              Интеграция с GraphQL (imtguigql)                 │
│  GqlRequest · SubscriptionClient · CollectionRepresentation │
├─────────────────────────────────────────────────────────────┤
│           Фреймворк приложения (imtgui)                      │
│  ApplicationMain · PagesManager · Settings · Params          │
├─────────────────────────────────────────────────────────────┤
│            Базовые UI-компоненты (imtcontrols)                │
│  Buttons · Inputs · Views · Dialogs · Models · Actions       │
├─────────────────────────────────────────────────────────────┤
│              JQML – Web Runtime & Compiler                   │
│           v1 (PureQML) · v2 (JQML2) · v3 (JQ)              │
└─────────────────────────────────────────────────────────────┘
```

### Цепочка зависимостей

```
imtcontrols (Базовый UI-фреймворк)
    ↓
imtgui (Фреймворк приложения, использует imtcontrols)
    ↓
imtguigql (Интеграция с GraphQL, использует imtgui)
    ↓
Доменно-специфичные модули:
├── imtauthgui  (Аутентификация и пользователи)
├── imtchatgui  (Система чата)
├── imtcolgui   (Управление коллекциями)
├── imtdeskgui  (Система тикетов)
├── imtdocgui   (Управление документами)
├── imtlicgui   (Управление лицензиями)
├── imtgeogui   (Гео-визуализация)
├── imt3dgui    (3D-визуализация)
└── web         (Веб-специфичные компоненты)
```

## 🌐 JQML — QML для веба

JQML — это набор инструментов компиляции, который транспилирует QML-код в JavaScript, позволяя использовать одну и ту же кодовую базу QML как в нативном десктопном приложении Qt, так и в веб-приложении, работающем в браузере.

| Версия | Название | Описание |
|--------|----------|----------|
| **v1** | PureQML | Первое поколение веб-компилятора |
| **v2** | JQML2 | Расширенная версия с поддержкой 3D (Three.js), 130+ компонентов |
| **v3** | JQ | Текущее поколение с собственным парсером, Source Maps, 60+ типов QtQml + 50+ типов QtQuick |

➡️ Подробности: **[Руководство JQML](QML_JQML_Guide.md)**

## 📦 Модули на один взгляд

### Основные UI-модули

| Модуль | Компоненты | Описание |
|--------|------------|----------|
| `imtcontrols` | ~160 | Базовый UI-фреймворк: Buttons, Inputs, Views, Dialogs, Models, Actions, GraphicsView |
| `imtgui` | ~90 | Фреймворк приложения: ApplicationMain, Panels, Params, Settings, Views |
| `imtguigql` | ~35 | Интеграция с GraphQL: GqlRequest, Subscriptions, управление коллекциями |

### Доменно-специфичные модули

| Модуль | Описание |
|--------|----------|
| `imtauthgui` | Вход, регистрация, управление тенантами, панель пользователя |
| `imtchatgui` | Интерфейс чата и обмен сообщениями |
| `imtcolgui` | Управление и отображение коллекций |
| `imtdeskgui` | UI системы тикетов |
| `imtdocgui` | Управление документами и редактор |
| `imtlicgui` | Интерфейс управления лицензиями |
| `imtgeogui` | Визуализация гео-данных |
| `imt3dgui` | 3D-сцены и визуализация |

### Веб-специфичные

| Модуль | Описание |
|--------|----------|
| `web` | Веб-специфичные QML-компоненты для сборок JQML |

➡️ Подробности: **[Справочник модулей](QML_Module_Reference.md)**
